Creates a webhook for Pull requests and Issue comments, JSON, signed with this server's WEBHOOK_SECRET. The token needs Webhooks: read and write.

Manual setup (from the README)
  1. Set a webhook secret. Put a random string in .env as WEBHOOK_SECRET (e.g. from python -c "import secrets; print(secrets.token_hex(32))"). Without it the server rejects every delivery.
  2. Start the server: driftless serve (http://127.0.0.1:8000).
  3. Create a smee channel at smee.io (Start a new channel) and copy its URL.
  4. Forward it to the server: npx smee-client --url https://smee.io/<id> --target http://localhost:8000/webhook
  5. Add the webhook on GitHub: Settings → Webhooks → Add webhook. Payload URL: your smee URL; Content type: application/json; Secret: the same value as WEBHOOK_SECRET; events: Let me select individual events → Pull requests and Issue comments (untick Pushes); Active.
  6. Check it. GitHub sends a ping right away; the server log shows POST /webhook 200 and Recent Deliveries shows a green tick.
